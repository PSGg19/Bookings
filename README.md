# 🏨 Hotel Booking System (CLI-Based)

A **Command-Line Interface (CLI) Java Project** that allows users to **book, manage, and cancel hotel rooms**. This system supports both **regular users** and **administrators** with distinct functionalities.

🔹 **Users** can:
- **View available rooms**
- **Book and cancel rooms**
- **View their bookings**

🔹 **Admins** can:
- **Manage all bookings**
- **View room availability**
- **Add new rooms to the system**

---

## 🛠️ Technologies Used
This project follows **Object-Oriented Programming (OOP)** principles and uses **file handling** for persistent storage.

| Feature                  | Technology Used |
|--------------------------|----------------|
| **Programming Language** | Java 17 (or later) |
| **OOP Concepts**         | Encapsulation, Inheritance, Polymorphism |
| **Persistent Storage**   | File Handling (Text-Based) |
| **CLI Framework**        | Java Console |
| **Version Control**      | Git & GitHub |
